# Knightfly — playable test build

Open it on a phone: **https://raz19levi.github.io/knightfly-play/**

Landscape. Grab an attacker with your finger, drag it off the ground and
flick it away. Tap the machines on the castle to use them.

This repository holds a build and nothing else. The source is private.
Every asset in it is ours: the art is drawn and rendered by our own tools
(some stills painted over our own renders), every word on screen is our own
wording, the sound is synthesised by a script in the source repository, and
no byte of any other game ships here.
